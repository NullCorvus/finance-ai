# Taste — Communication & Workflow
- Prefers to work in English for code, docs, and communication, even when their native language is Spanish (asked to translate everything to English and reply in English). Confidence: 0.9
- Wants unfamiliar domain terms or options explained before deciding on them (repeatedly asks "what is that?" / "explain this" before committing). Confidence: 0.6
- Likes planning artifacts (context, features, scope, decisions) stored as markdown files inside the repo (e.g., `docs/CONTEXT.md`, `docs/FEATURES.md`, `docs/ALCANCE.md`). Confidence: 0.8
- Prefers consolidating decision records into the main planning docs rather than maintaining a separate decisions document. Confidence: 0.7
- Wants confirmed decisions written to markdown files immediately as they are made during planning, not deferred to the end. Confidence: 0.7
- Prefers features/tasks explicitly prioritized into phases and marked as must-do vs. optional/nice-to-have, and cares that nice-to-haves are not mislabeled as core phase work. Confidence: 0.8
- Prefers to defer detailed design decisions that depend on not-yet-decided tech choices (e.g., UI format) rather than speculate early. Confidence: 0.7
- For defining a project idea, prefers an interviewer-style Q&A (assistant asks structured questions, user answers, assistant organizes), ending with a summary the user confirms before it's written to a file. Confidence: 0.6
- Prefers to be able to review the complete current plan again before approving or requesting revisions. Confidence: 0.8
- Prefers LaTeX/document templates and format conversions to live inside the repository (co-located with code/docs) and asks where in the repo to place them rather than keeping them externally. Confidence: 0.8
- Wants institutional Word/PDF to LaTeX conversions to be pixel-perfect 1:1 clones — same format, layout, and original logos preserved. Confidence: 0.9
- Expects both the DOCX and PDF versions of a source document to be consulted when replicating an institutional format. Confidence: 0.75
- Prefers external normative/guideline PDFs (e.g., Lineamientos PGC) to be transcribed into a structured, directory-scoped `CONTEXT.md` co-located with the relevant artifact (e.g., `latex/CONTEXT.md` for PGC) rather than left as external file references. Confidence: 0.8
- Prefers to keep subsystem contexts separate — preserves `docs/CONTEXT.md` for the main project and creates a distinct `latex/CONTEXT.md` for LaTeX/PGC — and expects the original to be restored if overwritten rather than merging into a single global context file. Confidence: 0.85
