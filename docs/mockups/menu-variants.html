Por qué estas 3 (y no las anteriores)

Proyecto es prototipo académico UdeC (no fintech comercial). Objetivo PGC reducir esfuerzo de captura y sostener hábito beyond 30 días. Las 4 variantes anteriores añadían fricción (drawer +1 tap) o peso visual (dock blur 32px, notch FAB) que contradicen ALCANCE.md y no existen en Flutter nativo. Estas 3 mantienen mismo paradigma bottom nav 3 tabs, solo pulen el activo.

Flutter NavigationBarUdeC verde #6B8E00COP defaultSin +taps

V0 — Actual (baseline)

Nav plano, `border-top:var(--line)`, activo solo color `var(--primary)`. Funciona pero activo poco visible, `var(--nav:#9CA3AF)` demasiado claro en `var(--bg:#F5F6F8)`, sin indicador táctil.

altura 52pxsin indicadorcontraste bajo

V1 — Material 3 NavigationBar ★ recomendada

Pill `56×30` `var(--primary-soft)` detrás del icono activo + label `700` `var(--text)`. Espacio negativo correcto, elevación sutil `0 -4px 16px`. Es el componente que Flutter genera con `NavigationBar` sin código extra — menor riesgo sprint Scrum.

pill 56×30label 700Flutter nativocontraste AA
  • ✓ Activo inequívoco a 40cm (piloto estudiantes)
  • ✓ Mantiene capture bar separado 0 fricción
  • ✓ Light/dark ya resuelto `var(--primary-soft)`

V2 — Pill suave (tab completo)

Todo el tab activo es pill `var(--primary-soft)` circular. Más color, activo ocupa todo el ancho. Útil si el piloto usa el app bajo sol y necesita alto contraste.

pill full-widthbg var(--soft)alto contraste

V3 — Minimal académico

Solo `border-top 2.5px` + punto `4px` + label `700` verde. Máximo aire, tono más formal UdeC, ideal para defensa PGC/sustentación. Menos “app comercial”, más “prototipo serio”.

línea 2.5pxpunto 4pxmuy limpio
Captura-first intacta
Shutter 54px `var(--primary)` hero + `🎤` + `✎` + `textfield` siguen arriba del nav con gap 8px y `border-top:var(--line)`. No se integran en el nav — la foto sigue siendo acción #1 sin competir con tabs. Respeta `MOCKUPS.md` prioridad `📷 > 🎤 > ✍️ > texto`.

Abre `docs/mockups/index.html` para ver el original. Esta página es solo comparador.
