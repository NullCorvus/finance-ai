# Entrega — Documentación del proyecto Finance AI

Documentos de la versión en línea (servidor FastAPI + cliente Flutter para Android y Windows), elaborados con las
plantillas de la asignatura (ver [`../plantillas`](../plantillas)). Cada documento está en Word y en PDF.

| Elemento de la entrega | Word | PDF |
| --- | --- | --- |
| Manual de usuario | [docx](Manual%20de%20usuario%20-%20Finance%20AI.docx) | [pdf](Manual%20de%20usuario%20-%20Finance%20AI.pdf) |
| Manual técnico | [docx](Manual%20tecnico%20-%20Finance%20AI.docx) | [pdf](Manual%20tecnico%20-%20Finance%20AI.pdf) |
| Diccionario de datos | [docx](Diccionario%20de%20datos%20-%20Finance%20AI.docx) | [pdf](Diccionario%20de%20datos%20-%20Finance%20AI.pdf) |

Archivos del diccionario de datos:

- [Diccionario_Datos_Finance_AI.xlsx](Diccionario_Datos_Finance_AI.xlsx): hoja de cálculo.
- [Diccionario_Datos_PostgreSQL.sql](Diccionario_Datos_PostgreSQL.sql): consulta adaptada a PostgreSQL.
- [Diccionario_Datos_Comentarios.sql](Diccionario_Datos_Comentarios.sql): sentencias `COMMENT ON` con las descripciones.

Los documentos de Word tienen tabla de contenido: al abrirlos, Word pregunta si desea actualizar los campos; responda
**Sí** para generarla. Los PDF se generaron a partir del mismo contenido.
