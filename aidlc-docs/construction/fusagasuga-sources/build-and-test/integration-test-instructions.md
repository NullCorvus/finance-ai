# Navegación y revisión visual

Verificadas en el navegador las escenas 7 y 13 y el diálogo de referencias. El enlace «Referencias» abre un diálogo con todas las fuentes; no añade escenas al recorrido. E abre el mapa de rúbrica, Esc devuelve al punto anterior y F no abre respaldo. El recorrido automático se detiene en la demo. Las tarjetas de fuentes no desbordan sus contenedores. Sin errores de aplicación observados; los avisos visibles de consola proceden de la extensión del navegador.
