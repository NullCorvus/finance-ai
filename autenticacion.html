Inicio de sesión

Flutter usa una credencial Bearer. El portal web utiliza cookies.

Android · Flutter

  1. Inicia sesión

    La app envía el correo y la contraseña a POST /auth/login. FastAPI devuelve dos credenciales.

  2. Usa la sesión

    Flutter envía la credencial de acceso como Bearer en cada petición protegida.

  3. Renueva

    Flutter envía la credencial guardada en el almacenamiento seguro a POST /auth/refresh y recibe un nuevo par.

Portal web · React

  1. Inicia sesión

    El portal envía el correo y la contraseña a POST /staff/auth/login. Administración y Auditoría también verifican un código.

  2. Usa la sesión

    La API entrega dos cookies. El navegador adjunta la de acceso al pedir tickets u otros datos.

  3. Renueva

    El navegador envía la cookie de renovación a POST /staff/auth/refresh y recibe cookies nuevas.

Las rutas del diagrama comparten el prefijo /api/v1.
